​OVERVIEW
The PayFlow API allows developers to initiate and verify mobile money transfers across West Africa. This guide provides clear endpoints, authentication steps, and working code examples in Python and JavaScript.
​• Base URL: https://api.payflow.example.com/v1
• Format: JSON
• Authentication: Bearer Token (API Key)
​AUTHENTICATION
Include your secret API key in the Authorization header of every HTTP request:
​Authorization: Bearer YOUR_SECRET_API_KEY
Content-Type: application/json
​ENDPOINTS: 1. INITIATE A TRANSFER
Creates a new payment transfer to a recipient's mobile wallet.
​• Method: POST
• Endpoint: /transfers
​Request Parameters:Parameter Type Required Description
amount integer Yes Amount to send in minor units (e.g., 500000 for ₦5,000.00).
currency string Yes 3-letter ISO currency code (e.g., NGN).
recipient_phone string Yes Recipient phone number in E.164 format (+234...).
reference string Yes Unique transaction ID generated by your system.Python Code Example (requests)
import requests
​url = "https://api.payflow.example.com/v1/transfers"
headers = {
"Authorization": "Bearer YOUR_SECRET_API_KEY",
"Content-Type": "application/json"
}
payload = {
"amount": 500000,
"currency": "NGN",
"recipient_phone": "+2348000000000",
"reference": "TXN_987654321"
}
​response = requests.post(url, json=payload, headers=headers)
print(response.json())
​JavaScript Code Example (fetch)
const url = "https://api.payflow.example.com/v1/transfers";
​fetch(url, {
method: "POST",
headers: {
"Authorization": "Bearer YOUR_SECRET_API_KEY",
"Content-Type": "application/json"
},
body: JSON.stringify({
amount: 500000,
currency: "NGN",
recipient_phone: "+2348000000000",
reference: "TXN_987654321"
})
})
.then(res => res.json())
.then(data => console.log(data))
.catch(err => console.error(err));

​ERROR CODES
Status Code Meaning Resolution
400 Bad Request Missing or invalid parameter     Check that amount is an integer and currency is valid.
401 Unauthorized Invalid or missing API.         key Verify your Bearer token in the request header.
409 Conflict Duplicate transaction reference.    Generate a new unique reference string and retry.
